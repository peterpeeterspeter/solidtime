# Keyboard Shortcuts Reference

Timeclocker is designed for keyboard-first workflows. This guide covers all available keyboard shortcuts to help you track time efficiently.

> **Platform Note**: On macOS, use `⌘` (Command). On Windows/Linux, use `Ctrl`.

## Quick Reference

Press `?` or `Shift+?` anywhere in the app to see the keyboard shortcuts modal.

---

## Global Shortcuts

These shortcuts work throughout the entire application:

| Shortcut | Action | Description |
|----------|--------|-------------|
| `⌘/Ctrl + K` | Command Palette | Open universal command palette for quick actions |
| `⌘/Ctrl + T` | Start/Stop Timer | Toggle timer for current or last-used project |
| `⌘/Ctrl + Shift + T` | New Timer | Start a new timer with project selection |
| `⌘/Ctrl + F` | Search | Search time entries, projects, or clients |
| `?` or `Shift + ?` | Help | Show keyboard shortcuts modal |
| `Esc` | Close/Cancel | Close modals, dialogs, or cancel current action |

## Timer Shortcuts

Control the timer without leaving your keyboard:

| Shortcut | Action | Description |
|----------|--------|-------------|
| `⌘/Ctrl + T` | Start/Stop | Toggle timer for current or last project |
| `⌘/Ctrl + Shift + T` | New Timer | Start fresh timer with project picker |
| `⌘/Ctrl + Shift + S` | Save Entry | Save current time entry |
| `⌘/Ctrl + Shift + X` | Discard Entry | Discard current time entry |

**When Timer Modal is Open:**
- `↑/↓` - Navigate project list
- `Enter` - Select project and start timer
- `Tab` - Move between fields (description, billable, etc.)
- `Esc` - Close modal without starting

## Command Palette

The Command Palette (`⌘/Ctrl + K`) is your universal search and action center.

**Available Commands:**
- Start/stop timer
- Create new time entry
- Create invoice
- Navigate to any page
- Search recent projects
- Quick actions

**Using the Command Palette:**
1. Press `⌘/Ctrl + K` to open
2. Type to search commands, projects, or actions
3. Use `↑/↓` arrow keys to navigate results
4. Press `Enter` to execute selected command
5. Press `Esc` to close

**Tips:**
- Fuzzy search: Type partial words (e.g., "cre inv" finds "Create Invoice")
- Recent actions appear at the top
- Categories: Timer, Navigation, Invoices, Time Entries

## Advanced Tips

### Power User Workflows

**Fastest Way to Start Timer:**
1. Press `⌘/Ctrl + T` → Timer starts on last project
2. Press `⌘/Ctrl + K` → Type project name → `Enter`

**Quick Invoice Creation:**
1. Go to Time Entries (`⌘/Ctrl + Shift + E`)
2. Select entries with `Space` or `⌘/Ctrl + A`
3. Press `I` to create invoice
4. Review and press `⌘/Ctrl + Shift + S` to generate PDF

**Navigate Without Mouse:**
1. `⌘/Ctrl + K` to open command palette
2. Type destination (e.g., "reports")
3. `Enter` to navigate

## Troubleshooting

**Shortcuts not working?**
1. Check if you're focused on an input field (press `Esc` to blur)
2. Ensure your browser isn't blocking JavaScript
3. Try refreshing the page (`⌘/Ctrl + R`)
4. Check browser console for errors

**Conflicts with browser extensions?**
- Some extensions override keyboard shortcuts
- Try disabling extensions temporarily to identify conflicts
- Common conflicts: Vimium, Grammarly, language input tools

**Different keyboard layout?**
- Shortcuts are based on physical key positions
- QWERTY layout is assumed
- Non-QWERTY layouts may require different key presses
